# rn-escpos-printer

Reliable ESC/POS Bluetooth printing for React Native on iOS and Android

## Installation


```sh
npm install rn-escpos-printer
```


## Usage


```js
import { multiply } from 'rn-escpos-printer';

// ...

const result = multiply(3, 7);
```
